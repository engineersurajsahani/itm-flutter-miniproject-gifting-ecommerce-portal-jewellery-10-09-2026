# Gifting E-commerce Portal (Jewellery)

A complete jewellery e-commerce platform where clients browse products, add items to cart, proceed to checkout, and place orders. The system maintains order history and includes a comprehensive admin panel for product and order management.

## Key Focus Areas
- Product catalog & browsing
- Shopping cart & checkout process
- Order placement & history tracking
- Admin panel for inventory management
- Payment integration

## Tech Stack
- Flutter
- E-Commerce
